# Vertex X 0.4.1 — Native Windows setup

- Native C# WPF Lua workspace with dark editor, tabs, scripts library, console and settings
- Account sign-in against existing Zuzify Supabase with vertexx_ database tables
- Roblox public profile viewer (not verified Roblox account linking)
- Dark Inno Setup wizard with same-app upgrade, per-user install, shortcuts and uninstall
- In-app update checks use official GitHub Releases
- Manual build and release publishing without GitHub Actions

The installer is unsigned. Lua execution is in-process; do not execute untrusted Lua files.

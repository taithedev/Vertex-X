# Vertex X v0.5.2 beta

- Added save/discard/cancel prompts for edited tabs when closing a tab or exiting.
- Cancelling Save As or a failed save cancels closing, preserving the editor contents.
- Added a visible Close Tab button with the Ctrl+W shortcut.
- Toolbar wraps to fit smaller windows; title and badge display the exact installed version.
- Includes v0.5.1 beta update selection fixes, SHA-256 verified update downloads, self-contained Windows x64 setup, and scripts/settings preservation.

Unsigned beta. Cross-compilation, account/update regression checks and installer payload verification do not replace native Windows install, launch, update and uninstall testing. Updates require published release assets: the versioned EXE and SHA256SUMS.txt. No GitHub Actions are used.
